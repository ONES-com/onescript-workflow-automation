## Same-Version Installation

This same-version refresh keeps the formal ONEScript application version at `1.1.2` and adds the merged, target-tenant-accepted work-item status transition capability.

If ONEScript 1.1.2 is already installed, ONES Configuration Center will not accept different package bytes as an in-place upgrade. Uninstall the existing 1.1.2 package, then install the refreshed package above.

## Highlights

- `issue.transitTo("Done")` resolves the current work item's executable workflows, requires exactly one action reaching the exact target status, and executes that workflow.
- `issue.update({ Status: "Done", ... })` uses the same workflow chain and submits the accompanying fields with the transition.
- The optional `issue.transitTo` second argument is workflow form data only: `fields`, `comment`, `resources`, `timeEstimated`, and `timeSpent`.
- Status names and IDs are matched exactly. Unreachable and ambiguous transitions fail explicitly; the execution POST is never retried after an unknown transport outcome.
- Dry Run may read executable workflows to preview the status change, but sends no workflow execution POST.
- A visible `issueKey` Dry Run now loads the real current work-item snapshot before evaluating status and field conditions.
- A `taskPreAction` callback that omits Project or Issue Type can recover trusted scope from the official issue-detail path.
- A same-project guard is selected and executed; a proven other-project guard is excluded; unresolved potentially applicable scope still fails closed.
- Workflow-rule activation, worklog aggregate helpers, pre-action property compatibility, and HTTP Endpoint HMAC canonical-JSON interoperability remain included.
- The on-prem package retains App ID `LTRYTzJP`, platform Timer Task, and scripted-field abilities.
