# ONEScript v1.2.0

ONEScript 1.2.0 includes bug fixes and reliability improvements for script execution and the administration workspace.

## Install

1. Download `ONEScript-1.2.0-on-prem.opk` from Assets.
2. Open **Configuration Center > App management > Uploaded apps** in ONES.
3. Upload the package, then install and enable ONEScript.

This download is for **Private / On-Premises** deployments. ONEScript remains in early preview for evaluation and testing.

## Compatibility

The package declares an installation floor of ONES 3.16.37. This is **not a guarantee that all features work on that version**. Current features have additional platform requirements:

- Semantic issue search uses ONESQL, introduced in ONES 6.88.0.
- The issue change-log query helper requires ONES 6.104.0.
- Project-copy and async-task helpers require ONES 7.0.5.
- Complete field metadata uses `searchIssueFields` (implementation baseline: ONES 7.13.0+). Older deployments fall back to the legacy field list, which may omit fields.

A single minimum version for all features has not yet been validated. Validate the scripts and capabilities you need against your target ONES deployment before rollout.
