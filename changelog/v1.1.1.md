## Highlights

- Adds the taskPreAction-only `issue.worklog` aggregate for registered, estimated, remaining, and platform roll-up hours.
- Adds `hasSpent()`, `hasEstimate()`, `isOverEstimate()`, `varianceHours`, and `progressPercent` comparisons.
- Rejects safely when a required aggregate cannot be read instead of treating unavailable data as zero.
- Keeps unrelated guards on a zero-extra-request path and shares one aggregate read across matching worklog guards.
- Formally documents the complete, explicitly separated Simple and Summary worklog record helper surfaces.
- Aligns Dry Run, autocomplete, Guide, AI Skill, and the user manual with the runtime contract.

## Upgrade Notes

- Existing v1.1.0 scripts do not require migration.
- Use `issue.worklog` only in `taskPreAction`.
- Use worklog record writes only from write-capable L1 triggers.
- Select `openapi.worklog.simple.*` or `openapi.worklog.summary.*` from the team's worklog configuration; ONEScript does not probe or retry across modes.
