## Highlights

- Work more smoothly in the ONEScript workspace: authenticated actions reuse the active session, Dry Run completes through one ordered request, and draft-only edits avoid unnecessary published-rule refresh work.
- Let the Script IDE, Dry Run Context, output, Resources, and Automation content grow with the page. Expanded panels remain visible and the page scrolls naturally instead of clipping menus or squeezing the editor.
- Create scripts with a focused language selector that offers JavaScript and TypeScript directly, without an unnecessary search field.
- Use reliable Scripted Field controls in Resources: the field-type menu opens with a normal pointer click, the field-name input uses the standard focus treatment, and the published-script selector returns to its resting state after closing.
- Use consistent, localized controls across Resources and REST Endpoints, including published-script selectors, active states, empty results, refresh actions, and create actions.
- Run eligible published scripts on demand from the Script workspace, with confirmation, clear results, and direct navigation to execution history.
- Configure Timer rules using seconds, minutes, hours, or days, and open the exact execution history for each rule.
- Build native Float and Selection scripted fields, including dynamic option lists from arrays, providers, or issue searches.
- Continue large issue searches with an explicit Cursor and read-only `pageInfo`. Each call still returns 1-100 issues, while the previous application-level 1,000-item total limit has been removed.
- Use the same Cursor-based path from `selection.options.fromIssues()`, including exact saved-value lookup and an optional author-selected `maxItems` limit.
- Let ONES OAuth Endpoint Caller scripts update semantic fields, add comments, and transition issue status through public OpenAPI under the current caller's identity and permissions. Caller mode never falls back to Admin credentials.

## Known Limitations

Caller mode still cannot send Notify / Email effects, use Hosted API, or administer script variables.

Minimum supported ONES version: 3.16.37.
